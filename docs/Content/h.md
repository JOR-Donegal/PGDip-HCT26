# Week 8

Proxmox is based on Linux and we can cover some useful technology on a very modest host running under Hyper-V. Some of the technology I introduce here (ZFS, Ceph) is very significant.

Before you start, do some background reading on __Kernel Virtual Machines__ (KVM) in Linux. Also lookup the __Quick EMUlator__ (QEMU). You used these tools in the Networking module with GNS3, but without us digging deeply into them.
