Introduction

This site contains basic notes in Hybrid Cloud Technology.

Welcome to this module, Hybrid Cloud Technology (HCT). I plan and orchestrate my modules with 10 weeks of examinable content, weeks 2-11. This module was arranged for e-delivery. If you are working remotely, you are on the correct module!

I reserve week 1 for introductions and getting started, with a little reading.

The major areas covered in weeks 2-11 are

  • Hardware Platforms
  • Desktop Virtualization
  • Server Virtualization
  • Storage and Networking Virtualization

I reserve week 12/13 for clean up at the end...or run over time if we need it.

This module is intended for students who already have some background in scripting and automation, networking and operating systems, ideally from previous modules on the same programme. It is assumed you already have an undergraduate degree in computing or a similar discipline. The material is thus pitched at people who can self-learn. The structure of this module was created c. 2015 and last revised in 2022. The content is updated annually.

This version of the module is intended for e-delivery.

You are doing this module remotely, you need a good modern computer, review my notes in Week 1 to understand what you need.
